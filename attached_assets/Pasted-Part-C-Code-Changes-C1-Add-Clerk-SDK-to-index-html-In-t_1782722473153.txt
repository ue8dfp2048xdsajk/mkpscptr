Part C — Code Changes
C1 — Add Clerk SDK to index.html
In the <head>, after the Fabric.js script tag:

<script
  async
  crossorigin="anonymous"
  data-clerk-publishable-key="pk_live_YOUR_KEY_HERE"
  src="https://[YOUR_CLERK_FRONTEND_API].clerk.accounts.dev/npm/@clerk/clerk-js@latest/dist/clerk.browser.js"
  type="text/javascript"
></script>
Clerk provides the exact script tag in your dashboard under API Keys → Quick Copy. Copy it verbatim.
C2 — Add auth UI container to index.html
The header-center div is currently empty. Add an auth container there:

<div class="header-center">
    <div id="clerkAuthContainer"></div>
</div>
C3 — Initialize Clerk in app.js
At the top of app.js, after var _userPlan = 'free', add an init block that:
8. Waits for the Clerk SDK to be ready
9. Checks if the user is signed in
10. Sets _userPlan from user.publicMetadata.plan (you'll set this via dashboard or webhook in Phase 3 — for now it defaults to 'free')
11. Renders either a Sign In button or an avatar+dropdown
12. Calls _refreshAllProStarBadges() so watermarks update immediately
The rough structure:

window.addEventListener('load', async () => {
    await window.Clerk?.load();
    const user = window.Clerk?.user;

    if (user) {
        _userPlan = user.publicMetadata?.plan || 'free';
        _refreshAllProStarBadges();
        _renderUserAvatar(user);
    } else {
        _renderSignInButton();
    }
});
C4 — _renderSignInButton() function
Inserts a "Sign In" button into #clerkAuthContainer. On click:

sessionStorage.setItem('ms_redirect_after_auth', window.location.href);
window.Clerk.openSignIn();
C5 — _renderUserAvatar(user) function
Inserts into #clerkAuthContainer:
• User's profile image (Clerk provides user.imageUrl)
• A small dropdown on click with: account email, Log Out button
• Log Out calls window.Clerk.signOut() then reloads
C6 — Export gate: redirect to sign-in instead of alert
Currently the free-plan export gate does alert(...). Change it to:

if (!window.Clerk?.user) {
    sessionStorage.setItem('ms_redirect_after_auth', 'export');
    window.Clerk.openSignIn();
    return;
}
C7 — Post-auth redirect handler
On app load, after Clerk initialises, check sessionStorage:

const redirect = sessionStorage.getItem('ms_redirect_after_auth');
if (redirect === 'export' && window.Clerk?.user) {
    sessionStorage.removeItem('ms_redirect_after_auth');
    document.getElementById('exportBtn').click();
}
C8 — Listen for auth state changes
Clerk fires events when users sign in/out mid-session:

window.Clerk?.addListener(({ user }) => {
    if (user) {
        _userPlan = user.publicMetadata?.plan || 'free';
    } else {
        _userPlan = 'free';
    }
    _refreshAllProStarBadges();
});
