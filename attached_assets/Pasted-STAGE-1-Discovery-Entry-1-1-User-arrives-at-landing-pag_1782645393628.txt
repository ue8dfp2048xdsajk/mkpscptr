STAGE 1 — Discovery & Entry
1.1 User arrives at landing page
• Headline, value prop, screenshot/GIF of finished mockup grid
• Single CTA: "Launch App →"
1.2 User clicks through → arrives at the app
• Top bar: logo (left), About / Pricing / nav links (centre), Log In / Sign Up (right)
• Canvas area shows: "Drag background images here"
• Left sidebar collapsed by default
• vpControlPanel visible (Cols, Row gap, Col gap)

STAGE 2 — Free Testing (No Account Required)
2.1 User drags on background images
• Backgrounds appear in the grid, no watermark
• User can arrange, reorder, adjust col/row count freely
2.2 User drags on design files
• Designs composite onto all backgrounds
• Watermark appears on every window
• A subtle flash/pulse prompt appears in the top bar: "Remove watermarks — upgrade to a paid plan" with a small ✕ to dismiss
• Prompt persists (or re-appears on hover) until dismissed or user upgrades
2.3 User explores the left sidebar — two categories:
Free features (Layers, Appearance, Mockup sections):
• Apply as normal, no restriction
• Watermark stays but effect is visible
PRO features (Warp & Perspective, Clipping, Painting, Create Pattern, Framing, Background Adjustments):
• Each section header and control shows a yellow ⭐ PRO badge
• User can interact with these controls freely
• Effect is applied and visible on canvas — but that window is now marked with a yellow ⭐ badge (corner of the canvas wrapper)
2.4 User selects windows and uses Fabric handles (transform, scale, rotate)
• Works normally for all users
• Watermarks stay in place through all transforms

STAGE 3 — Export Gate
3.1 User clicks Export → dropdown appears (Export Selected, Export All, PNG/JPG/quality options)
• User selects any export option
3.2 System silently saves project state:
• Serialises current project to JSON (including per-window ⭐ PRO star flags and all layer/adjustment state)
• POSTs anonymously to server → assigned a UUID → stored server-side
• UUID saved to sessionStorage as fallback
3.3 User is redirected to the Plans page
• Banner at top: "Export your mockups — choose a plan to continue"
• Annual pricing tab selected by default

Branch A — User picks FREE:
• → Login / Create Account prompt
• Account confirmed as Free tier
• Anonymous project UUID linked to account
• → Dashboard (can return to app and export with watermark only)
Branch B — User picks STARTER or PRO (any billing period):
• → Login / Create Account prompt
• Chosen plan + billing period remembered throughout auth
• → Stripe Checkout for that specific plan (Stage 5)
Branch C — User already logged in:
• Skips login prompt entirely
• Branch A path → Dashboard
• Branch B path → straight to Stripe Checkout
Branch D — User dismisses / backs out:
• → Redirected to Dashboard (if logged in) or back to app (if not)
• Anonymous project UUID preserved — linked to account if/when they later sign up

STAGE 4 — Login / Create Account
4.1 Options presented:
• Continue with Google (one click)
• Continue with email — enter email + password → account created immediately
• Already have an account? Log in
No email verification at this step — verification is sent at payment (Stage 5). Frictionless account creation is the priority here.
4.2 After auth completes:
• If came from Branch A (Free) → Dashboard
• If came from Branch B (Starter/Pro) → Stripe Checkout with plan pre-selected

STAGE 5 — Checkout (Stripe)
5.1 Stripe checkout (hosted page or embedded Elements):
• Order summary: plan name, billing period, price
• Discount/promo code field
• Credit/debit card entry
• Pay button
5.2 Payment succeeds:
• Stripe webhook updates account plan in database instantly
• Receipt emailed immediately
• Email verification link sent at this point (tied to payment confirmation)
• → Dashboard with success banner: "You're now on [Starter / Pro]!"
• Anonymous project UUID linked to account and available in Projects
5.3 Payment fails:
• Stripe handles card error inline
• User retries — no redirect, no lost state

STAGE 6 — Dashboard
6.1 Default view: Projects
• Grid/list of saved projects with thumbnail, name, last edited date
• Projects containing ⭐ PRO-starred windows are visually flagged
• Click any project → reopens in app with full state restored
• + New Project button → opens blank app
6.2 Mockup counter (prominent on dashboard):
• "You've composited X mockups — saving you an estimated Y hours"
• Calculated at ~5 minutes per mockup manually
6.3 Plan badge visible top-right (Free / Starter / Pro)
• Starter/Free users see a subtle "Upgrade" link next to badge

STAGE 7 — In-App Plan Enforcement (Returning Users)
Free user:
• Watermark always on after design upload
• Free sidebar features work normally
• PRO controls usable → window gets ⭐ star
• Export → redirected to Plans page (Stage 3.3, skipping the save step since project is already saved)
Starter user:
• Watermark removed ✓
• All free sidebar features work normally
• PRO controls usable → window gets ⭐ star marker
• Exporting a ⭐ starred window → inline prompt: "This window uses a PRO feature. Upgrade to Pro to export it." → link to Plans page
• Exporting non-starred windows → exports normally, no watermark ✓
Pro user:
• Everything works, no restrictions, no watermarks, no stars ✓

STAGE 8 — Account & Settings
8.1 Top-right account button → dropdown:
• Dashboard
• Projects
• Settings
• Log Out
8.2 Settings sections:
• Personal: name, email, change password
• Plan & Billing: current plan, next renewal date, upgrade/downgrade/cancel
• Cancel → confirm modal, access continues to end of billing period
• Payments: invoice history, download receipts
8.3 Plan changes:
• Upgrade (Starter → Pro): prorated via Stripe, immediate access
• Downgrade (Pro → Starter): takes effect at end of billing period; ⭐ PRO-starred windows in existing projects remain flagged — Starter user cannot export them until upgraded again

STAGE 9 — Returning User (Repeat Session)
9.1 User returns to site:
• If logged in → top bar shows account avatar, "Dashboard" link visible
• Projects auto-saved to server during editing (debounced, ~every 30s)
9.2 New session options:
• From dashboard: click + New Project → blank app
• From app: drag fresh backgrounds → treated as new project, prompts to name/save
• Top bar: File → New Project
9.3 Resuming work:
• Click any project in dashboard → app loads with full JSON state restored
• All windows, layers, adjustments, ⭐ PRO stars intact exactly as left
